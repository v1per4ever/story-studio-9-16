# Story Studio 9:16

Профессиональный веб-редактор и генератор вертикальных историй, креативов и визуальных карточек в формате 9:16 (HD 1080×1920 px) для десктопа и мобильных устройств.

---

## Возможности

* **Адаптивный интерфейс для Desktop и Mobile**:
  * Десктоп: трехпанельная студия (левая лента миниатюр, центральный интерактивный холст 9:16, правый инспектор свойств).
  * Мобильные устройства: полноэкранный режим `100dvh`, нижняя док-панель навигации по слайдам и выдвижная шторка (Bottom Sheet) настроек.
* **10 готовых бизнес-шаблонов**:
  * Деловой заголовок (Editorial)
  * Цитата эксперта (Quote)
  * Кейс / Цифра + факт (Metric)
  * Фокус-тезис (Highlight)
  * Премиум-стекло (Glassmorphism)
  * Анонс прямого эфира / события (Announcement)
  * Чек-лист преимуществ (Checklist)
  * Карточка оффера с тарифом (Product / Offer)
  * Руководство / Менеджмент (Team Management: 2 эксперта в вертикальном стеке 9:16)
  * Юридический блок / Комплаенс (Team Legal: карточки юристов и патентных поверенных)
* **Назначения кадров и безопасные зоны (Safe Zones)**:
  * Stories (Instagram / Telegram) — защита зоны шапки и области реакций.
  * Shorts / Reels (YouTube / Instagram / VK) — адаптивная плотность и защита правого бара действий и нижнего блока описания.
  * Свободный макет (Free layout) — расширенная рабочая область для чистого контента.
* **Кадрирование и оформление фона**:
  * Масштабирование (Zoom до 2.2x), смещение по осям X и Y (Pan), регулировка размытия (Blur) и затемнения (0–95%).
  * Загрузка собственных фото, подборка деловых стоковых фото и минималистичных темных градиентов.
* **Интерактивные модули**:
  * Генератор векторных QR-кодов по URL с настраиваемым размером и подписью.
  * Брендинговый бейдж с индикатором активности (онлайн) и позиционированием сверху или снизу.
* **Экспорт, валидация и шеринг**:
  * Автоматический контроль переполнения контента и подгонка масштаба для исключения брака.
  * Экспорт одиночного слайда в JPG с честным разрешением 1080×1920 px.
  * Пакетный экспорт всех историй в единый ZIP-архив с индикатором прогресса.
  * Интеграция с Web Share API для прямой отправки в мобильные мессенджеры и соцсети.
* **Хранение проектов и история изменений**:
  * Надежное автосохранение в IndexedDB без жестких лимитов браузера на тяжелые фото.
  * Экспорт и открытие проектов в формате `.json` с валидацией схемы через Zod.
  * Поддержка Undo/Redo (`Cmd/Ctrl+Z`, `Cmd/Ctrl+Shift+Z`) с интеллектуальной группировкой правок.
  * Дублирование слайдов (`Cmd/Ctrl+D`).

---

## Стек технологий

* **Фреймворк**: React 19 + TypeScript (строгий режим `strict: true`, без `any`)
* **Сборщик**: Vite 8 (Rolldown)
* **Стилизация**: Tailwind CSS v4 (швейцарская журнальная типографика, нейтральная палитра Zinc/Slate, без эмодзи)
* **Иконки**: Lucide Icons
* **Рендеринг**: `html-to-image` с предварительным ожиданием шрифтов `document.fonts.ready`
* **Архивация**: JSZip
* **QR-коды**: QRCode
* **Валидация**: Zod

## Локальный запуск

```bash
# Установка зависимостей
pnpm install

# Запуск локального сервера разработки
pnpm run dev

# Проверка типов и сборка в dist/
pnpm run build

# Предпросмотр сборки
pnpm run preview
```

## Деплой на Netlify

В репозитории уже настроен файл конфигурации `netlify.toml`:

```toml
[build]
  command = "pnpm run build"
  publish = "dist"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

### Подключение через Netlify Dashboard:
1. Перейдите на [app.netlify.com/start](https://app.netlify.com/start).
2. Выберите **GitHub** в качестве провайдера Git.
3. Выберите репозиторий `v1per4ever/story-studio-9-16`.
4. Netlify автоматически подтянет параметры сборки из `netlify.toml`:
   * **Build command**: `pnpm run build`
   * **Publish directory**: `dist`
5. Нажмите **Deploy story-studio-9-16**. Сайт станет доступен по публичному адресу `https://<site-name>.netlify.app`.
