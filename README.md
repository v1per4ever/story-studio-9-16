Подробнее о философии проекта, архитектуре и манифесте читайте в документе [ABOUT.md](./ABOUT.md).

## Ключевые возможности

* **Адаптивный интерфейс для Desktop и Mobile**:
  * **Десктоп**: трехпанельная студия (левая лента миниатюр, центральный интерактивный холст 9:16, правый инспектор свойств).
  * **Мобильные устройства**: полноэкранный режим `100dvh`, нижняя док-панель навигации по слайдам и выдвижная шторка (Bottom Sheet) настроек.
* **10 готовых бизнес-шаблонов**:
  * **Деловой заголовок (Editorial)** — акцентная журнальная типографика.
  * **Цитата эксперта (Quote)** — оформленная мысль спикера или лидера мнений.
  * **Кейс / Цифра + факт (Metric)** — ключевой KPI и поясняющий контекст.
  * **Фокус-тезис (Highlight)** — минималистичный акцент на главном месседже.
  * **Премиум-стекло (Glassmorphism)** — карточка с матовым эффектом размытия фона.
  * **Анонс прямого эфира / события (Announcement)** — дата, время и спикер мероприятия.
  * **Чек-лист преимуществ (Checklist)** — структурированный список пунктов с иконками.
  * **Карточка оффера с тарифом (Product / Offer)** — коммерческое предложение с ценой и CTA.
  * **Руководство / Менеджмент (Team Management)** — 2 эксперта в вертикальном стеке 9:16.
  * **Юридический блок / Комплаенс (Team Legal)** — карточки юристов и патентных поверенных.
* **Назначения кадров и безопасные зоны (Safe Zones)**:
  * **Stories (Instagram / Telegram)** — защита зоны верхней плашки авторов и нижней области реакций/ответа.
  * **Shorts / Reels (YouTube / Instagram / VK)** — адаптивная плотность и защита правого бара действий (лайк, шеринг) и нижнего блока заголовка/музыки.
  * **Свободный макет (Free layout)** — расширенная рабочая область для чистого контента без рамок.
* **Кадрирование и оформление фона**:
  * Масштабирование (Zoom до 2.2x), смещение по осям X и Y (Pan), регулировка размытия (Blur) и затемнения (0–95%).
  * Загрузка собственных фотографий, подборка деловых стоковых фото и темных градиентов.
* **Интерактивные модули**:
  * Генератор векторных QR-кодов по URL с настраиваемым размером и подписью.
  * Брендинговый бейдж с индикатором активности (онлайн) и позиционированием сверху или снизу.
* **Экспорт, валидация и шеринг**:
  * Автоматический контроль переполнения контента и подгонка масштаба шрифтов для исключения брака.
  * Экспорт одиночного слайда в JPG с честным разрешением **1080×1920 px**.
  * Пакетный экспорт всех историй в единый ZIP-архив с индикатором прогресса.
  * Интеграция с Web Share API для прямой отправки в мобильные мессенджеры и соцсети.
* **Хранение проектов и история изменений**:
  * Надежное автосохранение в **IndexedDB** без жестких лимитов браузера на тяжелые фото.
  * Экспорт и открытие проектов в формате `.json` с валидацией схемы через **Zod**.
  * Поддержка Undo/Redo (`Cmd/Ctrl+Z`, `Cmd/Ctrl+Shift+Z`) с интеллектуальной группировкой правок.
  * Быстрое дублирование слайдов (`Cmd/Ctrl+D`).

## Стек технологий

* **Фреймворк**: React 19 + TypeScript (строгий режим `strict: true`, без `any`)
* **Сборщик**: Vite 8 (Rolldown)
* **Стилизация**: Tailwind CSS v4 (швейцарская журнальная типографика, палитра Zinc/Slate)
* **Иконки**: Lucide Icons
* **Рендеринг экспорта**: `html-to-image` с предварительным ожиданием шрифтов `document.fonts.ready`
* **Архивация**: JSZip
* **QR-коды**: QRCode
* **Валидация схемы**: Zod

## Быстрый старт и команды

```bash
# 1. Клонирование репозитория
git clone https://github.com/v1per4ever/story-studio-9-16.git
cd story-studio-9-16

# 2. Установка зависимостей (рекомендуется pnpm)
pnpm install

# 3. Запуск сервера для разработки
pnpm run dev

# 4. Проверка типов TypeScript без сборки
pnpm run typecheck

# 5. Продакшен-сборка
pnpm run build

# 6. Предпросмотр продакшен-бандла
pnpm run preview

# 7. Очистка каталога dist/
pnpm run clean
```

## Деплой

### 1. GitHub Pages
Деплой настроен автоматически через GitHub Actions при пуше в ветку `main`. Процесс описан в [.github/workflows/deploy.yml](.github/workflows/deploy.yml).

### 2. Netlify
Файл `netlify.toml` уже подготовлен:
```toml
[build]
  command = "pnpm run build"
  publish = "dist"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```
Для развертывания достаточно подключить репозиторий в панели Netlify — настройки сборки применятся автоматически.
